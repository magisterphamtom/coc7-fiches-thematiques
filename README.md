# CoC7 – Fiches investigateur thématiques

Habille la fiche investigateur de **L'Appel de Cthulhu 7e** (système CoC7, fiche V3 par défaut) sur Foundry VTT v13/v14, avec la même famille de thèmes que *Cartes de chat thématiques* et *Token Action HUD – Thèmes L'Appel de Cthulhu* :

| Thème | Esprit |
|---|---|
| Années 20 | Art Déco noir et or, Limelight / Special Elite |
| New York années 20 | Manhattan de nuit, chrome et ambre de Broadway |
| Par-delà les Montagnes Hallucinées | Carnet d'expédition 1933, encre bleue, tampon E.S.M. |
| New York 2026 | Verre fumé et lignes de métro |
| Antarctique 2026 | Tablette de station polaire, accent orange |

## Réglages (monde)
- **Thème des fiches 1933 (et sans époque)** — par défaut : Montagnes Hallucinées.
- **Thème des fiches 2025-2026** — par défaut : Antarctique 2026.
- Chaque réglage propose aussi *Aucun* (fiche d'origine) et *Même thème que les cartes de chat*.

L'époque d'un investigateur est celle choisie dans *CoC7 – Suivi de Chance du groupe*. Sans ce module, toutes les fiches prennent le thème 1933.

## Par fiche (Gardien)
Menu de la fenêtre (⋮) → **Thème de la fiche…** : automatique, aucun, comme le chat, ou l'un des cinq thèmes.

Seul l'affichage change : aucune donnée n'est modifiée, désactiver le module rend les fiches d'origine.

## Installation
Lien de manifeste : `https://github.com/magisterphamtom/coc7-fiches-thematiques/releases/latest/download/module.json`

## Limites
Fiche investigateur V3 uniquement (pas la fiche résumée, ni l'ancienne V2, ni les PNJ).
